# Bundled font licences

All seven fonts in this folder are licensed under the **SIL Open Font License, Version 1.1**.
They are used unmodified and are loaded locally with `@font-face`; no font is fetched over the network.
The canonical licence text is at <https://openfontlicense.org/open-font-license-official-text/> and each upstream copy lives under the `ofl/` directory of <https://github.com/google/fonts>.

| Font file | Authors' project | Upstream source |
| --- | --- | --- |
| `Anton-Regular.ttf` | The Anton Project Authors — <https://github.com/googlefonts/AntonFont> | <https://github.com/google/fonts/tree/main/ofl/anton> |
| `BebasNeue-Regular.ttf` | Dharma Type / The Bebas Neue Project Authors (Ryoichi Tsunekawa) | <https://github.com/google/fonts/tree/main/ofl/bebasneue> |
| `ArchivoBlack-Regular.ttf` | The Archivo Black Project Authors — Omnibus-Type | <https://github.com/google/fonts/tree/main/ofl/archivoblack> |
| `BowlbyOne-Regular.ttf` | Vernon Adams — the Bowlby One project | <https://github.com/google/fonts/tree/main/ofl/bowlbyone> |
| `Monoton-Regular.ttf` | Vernon Adams — the Monoton project | <https://github.com/google/fonts/tree/main/ofl/monoton> |
| `BlackOpsOne-Regular.ttf` | The Black Ops Project Authors | <https://github.com/google/fonts/tree/main/ofl/blackopsone> |
| `Pacifico-Regular.ttf` | The Pacifico Project Authors — <https://github.com/googlefonts/Pacifico> | <https://github.com/google/fonts/tree/main/ofl/pacifico> |

The font files are assets, not application source. None of the lettering, logos, shapes or scenery in this app copies Rockstar Games artwork, wordmarks or fonts.
